# BattleBuddy Bid Readiness Pass 3
## CarePath-Light Mobility + VA Architecture

This pass adds a scoped mobility assistance layer inspired by CarePath.

The goal is wellness and access support, not a transportation marketplace.

Included:
- Saved locations foundation
- Trip requests
- Assistance requests
- Trip audit events
- Encryption-ready mobility models
- VA integration architecture scaffold

Excluded intentionally:
- Driver dispatch
- Payments
- Provider marketplace
